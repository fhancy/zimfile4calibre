ZIM Import
==========

Import selected books from a Project Gutenberg OpenZIM (.zim) collection
into Calibre. The .zim file is treated as a catalog of many books, not as
a single ebook.

Features
--------
- Browse and search titles from the ZIM directory (no full-archive extract)
- Prefer native EPUB, then PDF; optional HTML→EPUB or HTML→PDF conversion
- Tags: ZIM, Gutenberg; identifier gutenberg:<id>
- Skips duplicates already in the library

Requirements
------------
- Calibre 6 or newer (tested on Calibre 9)
- OpenZIM v5 or v6 Gutenberg-style archives (namespaces A / I)

Out of scope
------------
- DevDocs, Wikipedia, and other non-Gutenberg ZIM collections
- Importing the entire ZIM as one book
